# Podklady pro atestacni otazky

Sem ukladej zdrojove soubory k vypracovanym otazkam.

Doporuceny format nazvu souboru:

```text
VII-01-skoliozy.md
VII-02-koxartroza.md
V-11-dmo.md
```

Idealni struktura jedne otazky:

```markdown
# VII.01 Skoliozy

## Zadani otazky
Skoliozy, rozdeleni, chirurgicke a konzervativni reseni, programy LTV, korzetoterapie

## Vypracovana otazka
Sem vlozit vlastni text.

## Klicove body
- ...
- ...

## Zdroje / poznamky
- ...
```

Z techto podkladu lze nasledne pripravit:
- vypracovanou otazku pro web,
- flashcards,
- testove otazky s odpovedmi a vysvetlenim.
